paper-radar

Pull recent papers on a topic from Crossref, then ask questions answered only from what got indexed.

Step 1 – build the index

  1. Crossref query the API for papers published in the last 180 days
  2. Filter drop records with no DOI, title, or usable abstract
  3. Embed & index MiniLM vectors upserted into a per-topic Chroma collection

Step 2 – ask it something

  1. Retrieve nearest abstracts by cosine distance
  2. Answer the model sees only those abstracts and must cite them
